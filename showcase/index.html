rei-kit — 106 accessible Vue 3 and Tailwind 4 components

One kit, every look. A Vue 3 component library for Tailwind CSS 4, themed by role rather than by colour on three independent axes: ten WCAG-checked palettes, four materials (quiet, glass, brutal, soft) and light or dark — each switched with one attribute, without touching a component.

Typed, tested and SSR-safe, with no runtime dependencies. MIT licensed. pnpm add rei-kit
